{% trans "Putting a backup back, and automatic backups (for the person who installs the system)" %}

Every night (Windows: deploy\windows\backup.bat in the Task Scheduler; docker compose: the "nightly" service does it at 2 am):

python manage.py backup

It makes the ZIP of the data, then copies the new photos to FILES_BACKUP_DIR (set it in .env, e.g. FILES_BACKUP_DIR=E:\CIA backup\files).

Restore (new PC, or after a big change went wrong): install the system, then in its folder run

python manage.py migrate
python manage.py restore_backup "backup_2026-01-31_22-00-00.zip"
python manage.py restore_files --from "E:\CIA backup\files"

The data there before restoring is saved as a new backup first. Nothing is deleted when the files are put back.
